# ESP32-S3 DevKitC-1 firmware (public binary)

`firmware.bin` here is **gitignored**. Generated by:

```bash
pnpm firmware:build:esp32:s3
# or all boards:
pnpm firmware:build
```

Local dev without PlatformIO uses a placeholder from `pnpm firmware:placeholder`.

See [`docs/esp32-s3-firmware.md`](../../../../docs/esp32-s3-firmware.md) for wiring, GPIO allowlist, and hardware verification.
