# ESP32-S3 CAM firmware (public binary)

`firmware.bin` here is **gitignored**. Generated by:

```bash
pnpm firmware:build:esp32:s3:cam
# or both boards:
pnpm firmware:build
```

Local dev without PlatformIO uses a placeholder from `pnpm firmware:placeholder`.

See [`docs/esp32-s3-cam-firmware.md`](../../../../docs/esp32-s3-cam-firmware.md) for wiring, GPIO allowlist, and hardware verification.
